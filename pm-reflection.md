How did you come up with your idea?
I like traveling and found out it always takes a long time to do a travel guide: find good places to visit, to eat, and to stay. So, I think it could be helpful to have a travel guide that provides a list of places to visit with couple of images.

How well did the collaboration with your developer work?
It's not that good, the developer was not doing things on time, I could not see the outcome till very later time. I'm frustrated with all the late works because I was really excited to see the results.

What did you learn about writing requirements?
When writing requirements, I try to be very detailed about things I want to see in the web page but I still leave some space for developer to freestyle. I think it's helpful to have the web page outline in the ppt which tells the framework straightforwardly.

Did you use any AI tools in this process? How?
I didn't use any AI tools in this process, but I do check on other travel guide website to see what needs to be included in the webpage like this.
